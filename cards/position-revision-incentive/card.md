# Position-Revision Incentive

## When
Debate systems, review systems, any multi-agent orchestration where agents CAN change their minds.

## Core logic
Default debate incentive points at "winning" → strawmen, trench-digging, fence-sitting. Point it at **revision**:

> Position revision = cognitive progress, not losing.

Real vs fake revisions:

| Fake | Real |
|------|------|
| "you have a point too" | "I was wrong because assumption X fails, structurally because..." |
| repositioning (same stance, new words) | split revision (keep the right part, drop the wrong part, redraw the boundary) |
| social concession | conditional revision ("if evidence X appears, I should switch to Y") |
| "everyone's right" | disagreement refinement ("we actually disagree about Y, not X") |

## Key insights
1. **Revision is the ONLY signal a debate produced knowledge** — zero-revision debates were ships passing. Read the revision table first when auditing an archive.
2. **Revision is information, not virtue**: grade the new information it produces (what failed, why, boundary redraw).
3. **Agent application**: add to debate prompts — "your revisions are recorded and scored; holding position scores nothing." Zero-sum → knowledge-production game.

## Case
148-session debate archive: headline stats read "8/8 revisions all A-grade" (a session where every participant revised under evidence) — the badge people compete for.

## Risks
- Performative revision inflation (strict quality gate).
- Power asymmetry → forced revisions (independent veto channel).
